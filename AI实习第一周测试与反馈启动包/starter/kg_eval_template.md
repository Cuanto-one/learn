# KG／RAG 评测记录模板

此模板用于建立可复核的评价流程。第一周可用 `ontology_exercise.md` 的 10 条合成材料做一次人工演练，建议 1 小时，计入第一周实现/复盘时间；不要求完成检索系统，也不计入 120 分钟首测。

只有候选标注且未经过独立复核时，应写“标注草案/自测”，不要称为可靠金标准。10 条合成材料只能检查小样例行为，不能证明真实领域泛化效果。

## A. 数据与金标准登记

| 字段 | 内容 |
|---|---|
| 材料、事件、设备实例数量；按现象/否定/冲突/未知分类计数 | |
| 标注单位：实体提及/规范实体/主张/问题/答案中的独立事实 | |
| 实体边界、类型、别名、身份合并规则 | |
| 关系方向、时间范围、否定和确认状态规则 | |
| 必须保留的来源字段与最小证据片段 | |
| 第一标注者、复核者、分歧与裁决记录 | |
| 开发、验证、最终测试划分 | |
| 同事件/同工单/改写或近重复材料如何避免跨集合 | |
| 数据与标准答案哈希，冻结时间，标签保管人 | |
| 测试后是否改了提示词/规则/阈值；若改则如何重新标记 | |

真实数据只在授权环境处理。公开合成演示和内部真实评测分别记录，不能将二者混在一个漂亮指标中。

## B. 单条标注与核验

| claim_id | 来源与证据片段 | 金标准（复核后） | 系统输出 | 实体/关系/极性/状态/时间是否正确 | 错误原因及裁决 |
|---|---|---|---|---|---|
| | | | | | |

先定义匹配规则：实体要求提及边界还是规范 ID 一致？关系是否连同极性、确认状态、时间一起匹配？一个“原因成立”与“怀疑原因成立”不能在严格评价中算同一结果。

## C. 可选指标：按实际阶段选，不为填满表格制造结果

| 指标 | 口径与必须同时报告的数量 | 本次结果 |
|---|---|---|
| 实体/关系 P、R、F1 | 先固定匹配单位；TP/FP/FN；微平均/宏平均选择 | |
| 设备实例链接准确率 | 正确链接数/有可核验身份的提及数；未知身份另列 | |
| 极性与确认状态正确率 | 正确数/有该标注的主张数；否定、怀疑、冲突、未知分项 | |
| 来源完整率 | 具有必填来源字段的主张数/输出主张数；有字段不代表支持成立 | |
| 证据支持率 | 经核验确由引用片段支持的输出主张数/被核验输出主张数；注明全量或抽样 | |
| 检索 Recall@k | 每题已标注相关证据中被检出的比例，再按预定方法汇总；金标准锚定原文位置，重叠分块命中同一证据只计一次；命中须覆盖预先约定的句子与条件；金标准不完整需说明 | |
| 回答事实支持率 | 回答中被证据支持的独立事实数/需证据的独立事实数；拆分规则先固定 | |
| 无依据确定结论数 | 在否定/冲突/未知题中错误输出确定根因的次数与总题数 | |
| 拒答/待复核效果 | 对应答题、不足证据题分别统计正确回答与合理待复核；防止靠全部拒答刷分 | |
| 性能与成本 | 数据规模、运行环境、总耗时/单题耗时、模型调用次数与可获得的费用 | |

分母为 0 时报告未定义或明确工具约定，不能悄悄视为 100%。同一个材料可以有多个主张；不能把重复改写当作独立案例扩大样本量。

## E. 对照实验与失败归因

在相同语料、问题集、生成模型与预算下选择合适对照：关键词检索、向量检索、加入结构化图关系。尚未实现的对照写“未做”，不要编数字。先证明基线可复现，再判断图结构究竟改善了哪些问题。

| 版本/对照 | 仅改变什么 | 哪类题改善/变差 | 原始计数与证据 | 结论与限制 |
|---|---|---|---|---|
| | | | | |

失败归因只选能被证据支持的层次：原文不足、标注有误、实体身份错误、抽取漏/错、关系/极性丢失、检索没召回、重排错误、生成超出证据、引用错误、接口或数据版本问题。
